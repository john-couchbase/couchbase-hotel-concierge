# NoSQL learning lab

Couchbase stores JSON documents under unique keys. SQL++ queries find documents by their properties; direct key-value operations retrieve a document by its known ID. Nested objects and arrays let one order hold its address and line items.

This section contains native tests of data size, indexes, direct reads, concurrency, partial updates, CAS conflict protection, expiration and transactions. See the accompanying report and evidence for measured results and limitations.

[Vector Search](../vector-search/README.md) is a separate track. Lexical/full-text search is queued next, including analyzers, stop words, stemming, synonyms and hybrid search.
